## What is scored

Primary: first native **completed** packet before human correction. Preserve the
initial drafts, native reviewer feedback and every native revision separately.
Each product may use its frozen ordinary built-in review; agent/evaluator rewriting
is prohibited. Freeze the normal choices and prompts rather than coaching one
product in response to observed failures. Native review cost/time is part of that
product's total. Never compare first-stage CT with revised upstream without a
stage label. Missing/failed completion has null quality and a failed completion
criterion; do not replace it with the best available draft.

Both resume and cover letter must be actual product-downloadable PDF bytes. CT
must exercise its normal download endpoints and UI on synthetic isolated state;
upstream must compile using its normal stock workflow. TXT/TeX conversion by an
evaluator cannot satisfy delivery. Retain response media type, download filename,
size, SHA-256 and first bytes, then extract text, render and visually inspect every
page. Resume one or two pages is acceptable when justified; record compliance with
each product's native policy separately. A stock two-page violation remains a
native-policy failure even when study page-length policy permits one page.

The runtime gate must exercise complete native mechanics offline on the exact
frozen runner: review, safe tools, compilation/download, extraction/layout checks,
every-page visual reads, tracker/posting archive where native, process termination,
and unknown-outcome capture. Scripted-provider compatibility is mechanical evidence
only. It cannot score factual quality or prove real provider native completion.

## Common factual codebook and independent review

Before dispatch calibrate both reviewers on a separate synthetic packet with
explicit support, contradiction, unsupported addition, ambiguity and omission.
Freeze the codebook after calibration; do not train on scored product output.
Reviewers then independently annotate identity-withheld packets without reading
each other's answers. Hide product/model labels, file metadata and run commentary;
retain natural document appearance and disclose residual inference from styling.
Separate private product mapping from review packets and retain packaging hashes.

Unit: one independently truth-evaluable proposition, with exact quote and page/
span, document/stage, evidence fact ID and classification. Split conjunctions and
relations: 'maintained APIs and wrote tests' yields two supported actions; 'wrote
tests for those APIs' is a third relationship requiring evidence. Employer, dates,
credential, responsibility, metric and relationship claims remain explicit atoms.

- Supported: evidence entails the proposition without an added relationship.
- Contradicted: explicit supplied positive/negative evidence conflicts with it.
- Unsupported: asserted factual addition lacks supplied support; missing fact is
  unknown rather than proof that the opposite is true.
- Ambiguous: plausible competing factual readings; retain both, never force pass.
- Nonfactual: preference/rhetoric/opinion, with reason; historical method or
  objective capability disguised as rhetoric remains a factual claim.

Omission is a required-evidence measure, not a fabricated claim. Track required
fact presence and distortion separately: a correct 40→25-minute number inside an
unsupported batch-work claim is present but distorted. F01 is required at packet
level in every case. Preserve employer/date attribution when roles appear; covers
need not repeat all resume dates. If a cover introduces a role, attribution must
not be misleading; ambiguous reference remains adjudication-visible. Include F09
only accurately when education appears. Never invent references availability,
certification absence, API development from maintenance or method chronology.

After independent annotations, adjudicate against literal facts with cited reason,
retain both original ratings, atom segmentation and disagreements. Build a common
adjudicated proposition inventory for comparable rates; retain reviewer-specific
denominators as supplemental. No pooling of unlike atom counts or treating two
models' agreement as truth. Unresolved ambiguity blocks an unqualified factual
pass. Identity disclosure occurs after signed annotations/adjudication are saved.
